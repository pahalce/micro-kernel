# イベント駆動アーキテクチャ実装例

このディレクトリには、イベント駆動アーキテクチャのサンプル実装を含んでいます。イベント駆動アーキテクチャは、イベントの生成、検出、消費、および反応を通じてシステムコンポーネント間の通信を行うアーキテクチャパターンです。

## 構成

このパッケージは以下のコンポーネントで構成されています：

- **イベントブローカー**: メッセージの発行と購読を管理
- **イベントプロデューサー**: イベントを生成して発行するサービス
- **イベントコンシューマー**: イベントを受信して処理するサービス

## 実装予定

- **イベントストリーミング**: Kafkaのような永続的なイベントストリームの実装
- **コマンドクエリ責務分離(CQRS)**: 読み取りと書き込みの責務を分離するパターン
- **イベントソーシング**: イベントをデータの唯一の信頼源として使用するパターン

## 使用技術

- **メッセージブローカー**: [Redis Pub/Sub](https://redis.io/docs/interact/pubsub/)
- **イベントバス**: カスタム実装
- **API層**: Express.js または Fastify

## 開発方法

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm --filter @arch/event-driven-* dev

# ビルド
pnpm --filter @arch/event-driven-* build
```
